## Overall Impression

Компетентно, но резко обрывается: пик — большой честный итог, дальше достойный спуск по карточкам и стеку месяцев, а лента просто заканчивается. Главный риск не вкус, а мобильная вёрстка: на 390px страница разъезжается по горизонтали (карточки, шапка, график, герой обрезаны).

## What's Working

1. Акцент-как-идентичность везде: полоса, доли, стек, чипсы — пять hexoscop без чтения подписей.
2. Честность как композиция: renderGaps внутри потока сводки + точное время вместо округлений.
3. Типографическое спокойствие: один системный стек, tabular-nums на всех сравнимых цифрах.

## Priority Issues

- **[P0] Горизонтальное переполнение на мобильном.** Обрезаны шапка (Кино/Книги/Обновить за краем), подзаголовок героя, полоса-доля, карточки (вторая колонка срезана), график и оговорки. Причина-кандидат: grid-элементы с min-width:auto и nowrap-заголовками внутри. Fix: min-width:0 на элементах сеток + проверка скриншотом 390px.
- **[P1] График «По месяцам» видно, но нельзя прочитать.** Нет легенды, значений без ховера, на мобильном значения скрыты вовсе, семантики для SR нет. Fix: строка легенды, видимые итоги месяцев, role=img + aria-label на столбцы.
- **[P1] Семантика для клавиатуры и SR.** Карточки role=button без aria-label, эмодзи не aria-hidden, график и полоса-доля — голые div, focus-visible только на карточках, смена экрана не объявляется. Fix: aria-labels, aria-hidden иконок, focus-visible всей интерактивности, роли/подписи графика.
- **[P2] Шапка — три навигации сразу.** Табы + 5 пилюль источников + экспорт + sync; источники дублируют карточки. Contested: пилюли — явное требование пользователя («навигация в хедере»), оставлено; дублирование зафиксировано как осознанное.
- **[P2] Кликабельность карточек не считывается.** Только lift 2px + tooltip. Fix: постоянная строка «Открыть всё за год →» акцентом на кликабельных; пустым — dashed-граница.
- **[P2] Sync — чёрный ящик до 40с.** Fix (lite): таймер секунд в лейбле кнопки; стриминг по источникам — отдельным заходом (нужен API прогресса).
- **[P3] Заголовки событий обрезаны в одну строку.** Эмоциональная нагрузка — имена игр/фильмов/книг. Fix: clamp 2 строки, субтитры поднять с faint до dim.
- **[P3] Мелочи точности:** pluralHours «1.4 → 1 час» при показе «1.4»; пустые месяцы — невидимый сливер 2px; detail__meta с двумя «·».
