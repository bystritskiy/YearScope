# Design System: YearScope

## Overview

**Creative North Star: "The Honest Ledger"**

YearScope — это тихая бухгалтерская книга времени, а не витрина. Тёмная, плотная, спокойная: один экран отвечает «куда ушёл год», и ни один пиксель не притворяется точнее данных, на которых стоит. Пять акцентных цветов — не декор, а система кодирования: каждая активность узнаётся по цвету в карточке, столбце графика, ленте и навигации. Типографика системная, цифры — всегда табличные. Движения почти нет: интерфейс должен ощущаться мгновенным инструментом, а не представлением.

**Key Characteristics:**
- Одна тёмная тема, зафиксированная через `color-scheme: dark`.
- Акцентный цвет = идентичность источника, применяется одинаково везде.
- Плоские поверхности с тональным наслоением вместо теней.
- Табличные цифры и сдержанная шкала заголовков (52 / 40 / 30 / 24).
- Состояния первичны: загрузка, пусто, ошибка и оговорки о данных — часть композиции, а не заплатки.

## Colors

Палитра — холодные графитовые нейтрали с пятью приглушёнными акцентами источников; предупреждений два (янтарь, красный).

### Primary

Нет единого primary-акцента: роль акцента распределена между цветами источников (см. Tertiary). Нейтральный текст `#e6eaf2` — ближайший аналог primary для интерактива.

### Tertiary

- **Игры, фиолетовый** (#7c5cff): карточки, график, лента, навигация — всё, что относится к gowithme.
- **Сериалы, циан** (#31b0d5): то же для myshows.
- **Кино, зелёный** (#40bf6a): то же для letterboxd.
- **Книги, янтарно-оранжевый** (#e0913a): то же для koshelf.
- **Тренировки, малиновый** (#e05a8a): то же для intervals.

### Neutral

- **Фон** (#0b0e14): страница и углублённые области.
- **Приподнятая поверхность** (#141922): карточки, панели, кнопки, дни ленты.
- **Утопленная поверхность** (#090c11): подложка полос-долей и футер.
- **Линия** (#232a36): границы 1px, разделители, неактивные состояния.
- **Текст** (#e6eaf2): заголовки, значения, основной контент.
- **Приглушённый текст** (#8b93a5): подписи, доли, второстепенный контент.
- **Едва видимый текст** (#79839a): метаинформация 10–12px (время обновления, ярлыки). Нижняя граница контраста WCAG AA (5.1:1 к фону) — светлее нельзя без потери иерархии, темнее нельзя по стандарту.
- **Предупреждение** (#e0a33a): оговорки о неполноте данных.
- **Ошибка** (#e05a5a): ошибки синхронизации.

### Named Rules

**The Stripe Rule.** Акцентный цвет источника появляется как тонкая верхняя полоса (2–3px) на его карточке и детальной шапке, как сегменты в полосах-долях и столбцах графика. Полоса — подпись, а не украшение: не переносить её на нейтральные поверхности.
**The Darkness Lock.** Светлой темы нет. Новые поверхности проектируются только в тёмных токенах выше; инверсия секции запрещена.

## Typography

**Display Font:** системный sans (-apple-system, BlinkMacSystemFont, Segoe UI, Roboto, Helvetica, Arial) (без веб-шрифтов — ноль зависимостей)
**Body Font:** тот же системный sans
**Label/Mono Font:** отдельного нет; цифры — системный шрифт с `font-variant-numeric: tabular-nums`

**Character:** нейтральный системный голос, уверенность — через вес и кегль, а не через характер шрифта. Эмодзи — штатные иконки активностей, не декор.

### Hierarchy

- **Display** (680, 52px/1, -0.03em): общий итог часов за год. Только сводка.
- **Headline** (680, 24px/1.2, -0.02em): заголовок страницы (`#page-title`).
- **Title** (650, 30px/1, -0.02em): часы на карточке активности; (660, 40px) — часы в детальной шапке источника.
- **Body** (400, 15px/1.5): лента, описания, футер.
- **Label** (550, 13px, приглушённый): заголовки панелей; (400, 11–12px, едва видимый): мета, ярлыки месяцев, штамп обновления.

### Named Rules

**The Tabular Numerals Rule.** Любое число, которое можно сравнивать взглядом (часы, доли, месяцы, штампы времени), — с `tabular-nums`. Пропорциональные цифры в данных запрещены.
**The No-Serif Rule.** Антиква не используется нигде: ни в заголовках, ни для emphasis. Выделение — весом и цветом в том же семействе.

## Layout

Один контейнер 1180px по центру, вертикальный ритм секциями по 20px. Сводка: итог → сетка карточек (`auto-fit, minmax(210px, 1fr)`, зазор 14px) → график 12 месяцев → оговорки. Лента: фильтр-чипсы → дни сверху вниз, свежее первым. Карточка источника: шапка → полный рейтинг → лента только этой активности.

Отзывчивость: до 760px шапка перестраивается в два ряда (навигация — отдельной строкой с горизонтальным скроллом), футер — в одну колонку, значения графика скрываются. График остаётся 12-колоночным grid с уменьшенным зазором.

## Elevation & Depth

Глубина — тональным наслоением, а не тенями: фон → приподнятая поверхность → утопленная подложка внутри неё (полосы-доли). Система плоская по умолчанию.

### Shadow Vocabulary

- **Всплывающее меню** (`0 8px 24px rgba(0, 0, 0, 0.35)`): только меню экспорта.
- **Плавающая кнопка** (`0 6px 20px rgba(0, 0, 0, 0.4)`): только кнопка «наверх».

### Named Rules

**The Flat-By-Default Rule.** Поверхности плоские в покое. Тень появляется только у элементов, оторванных от потока (меню, плавающая кнопка). Карточки и панели теней не имеют — у них граница 1px.

## Shapes

Одна шкала с задокументированным правилом: поверхности — 14px (карточки, панели, дни), контролы — 9px (кнопки, меню), мелкие интерактивные — пилюли 999px (чипсы, бейдж года), микродетали — 5–6px (сегменты графика, пункты меню). Полоса-доля и её сегменты — пилюля/переполнение. Смешение шкал вне правила запрещено.

## Components

### Buttons

- **Shape:** 9px, граница 1px линией.
- **Primary:** фон приподнятой поверхности, текст основной, паддинг 8px 15px, шрифт 13px.
- **Hover / Focus:** фон `#1c2330`, граница `#2f3847`. Фокус — видимое кольцо из палитры.
- **Disabled:** opacity 0.5, курсор default (кнопка синхронизации во время опроса).

### Navigation

- **Style:** текстовые вкладки 14px приглушённым, активная — основным текстом с подчёркиванием 2px; ссылки-источники — те же вкладки 13px с цветной точкой-идентификатором (7px, акцент источника).
- **Нахождение:** липкая шапка с блюром (аппроксимация матового стекла, не Apple Liquid Glass), бренд слева, действия справа.
- **Mobile:** вкладки уходят строкой ниже с горизонтальным скроллом без видимого скроллбара.

### Chips

- **Style:** пилюля, фон приподнятой поверхности, граница линией, текст приглушённый 13px.
- **State:** активный — заливка акцентом источника (`--chip-accent`), граница прозрачная, текст белый.

### Cards / Containers

- **Corner Style:** 14px.
- **Background:** приподнятая поверхность; сверху полоса 2px акцентом источника (см. The Stripe Rule).
- **Shadow Strategy:** нет (см. Flat-By-Default).
- **Border:** 1px линией; у кликабельной — подсветка акцентом и подъём на 2px при наведении.
- **Affordance:** у кликабельной — строка «Открыть всё за год →» приглушённым 12px; у пустой — пунктирная граница и подпись причины.
- **Internal Padding:** 16px 18px.

### Chart

Составные столбцы 12 месяцев, высота — доля от максимума (150px), сегменты — цвета источников с тултипами «источник: точное время». Над графиком — строка легенды «цвет — источник». Каждый столбец — `role="img"` с подписью «месяц: итог — доли», полоса итога — тоже с подписью. Пустой месяц — плоская подложка 4px. Значения месяцев видны всегда, включая узкие экраны.

### Journal feed

День — панель 14px: дата + день недели слева, точный итог справа; события — сетка «иконка / тело / время». События-агрегаты (`kind: day`) — приглушённым. Пустая лента — центрированная подпись, а не пустота.

### Detail + Ranking

Шапка источника — панель с полосой 3px акцентом; рейтинг — нумерованный список с полосой веса относительно первой строки. Кнопка «← к сводке» — текстовая, приглушённая.

### Gaps (оговорки о данных)

Маркированный список без буллетов по умолчанию: янтарный маркер — предупреждение, красный — ошибка; подпись источника — полужирным основным текстом. Панель скрывается, когда оговорок нет.

### Footer

Три колонки (о проекте + итог / источники со статус-точками / данные и экспорт), нижняя строка — штамп обновления и «Наверх ↑». Точки статуса — семантические (ок / выключен / ошибка), единственное место с декоративными точками в системе.

## Logo

Знак — «кольцо года»: круг из пяти сегментов в цветах источников (по часовой сверху: игры, сериалы, кино, книги, тренировки) с точкой-прицелом в центре. Сегменты — те же пять акцентов из палитры, шестого цвета и градиентов нет.

- `public/logo-mark.svg` — знак без фона: шапка (24px), футер (18px).
- `public/favicon.svg` — знак на плашке `bg-raised` с обводкой `line`: favicon, apple-touch-icon.
- `public/logo.svg` — горизонтальная сборка знак + YearScope светлым текстом: тёмные поверхности, OG-картинка.
- `public/logo-light.svg` — та же сборка тёмным текстом `#161b26`: светлые поверхности (шапка README).

### Named Rules

**The Logo Lock.** Сегменты не перекрашиваются, порядок цветов не меняется, точка — цвета текста поверхности. Знак не складывается с другими фигурами и не кладётся на фото.

## Do's and Don'ts

### Do:

- **Do** кодировать источник его акцентом везде, где он появляется.
- **Do** подписывать неполноту данных рядом с цифрой (панель оговорок, `covers_from`).
- **Do** держать цифры табличными, а время — точным (`81 ч 38 мин`), округление до часов — только для крупных итогов.
- **Do** скрывать панели целиком (`hidden`), когда данных для них нет, вместо заглушек.

### Don't:

- **Don't** вводить шестой акцентный цвет или градиент — палитра закрыта пятью цветами источников и нейтралями.
- **Don't** выносить русские тире «—» из подписей: это норма языка, а не мусор.
- **Don't** добавлять светлую тему, модалки и бесконечные анимации — их нет в мире продукта.
- **Don't** складывать карточки друг в друга и ставить тени плоским поверхностям.
- **Don't** показывать топы (`highlights`) как события ленты: у них нет даты.
